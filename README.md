A program that writes one funny out-of-office auto-reply, as if a houseplant sent it, to `/output/entry.txt`, for the make.fun competition [The Houseplant Out-of-Office](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047).

## Run it

```sh
python3 main.py
```

It writes the out-of-office reply below to `/output/entry.txt` (or to the path given as the first argument, or `$OUTPUT_PATH`). No network, no clock, no randomness. The out-of-office reply is 89 characters, inside the 1 to 120 gate.

> I am out of office. I am the cactus. I have no water, no patience, and no plans to reply.
